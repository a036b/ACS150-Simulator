محاكي ABB ACS150 بلغة Rust — Windows 10 64-bit

هذه نسخة مصدر Rust وليست ملف EXE مبنياً مسبقاً. أعددنا GitHub Actions
لبناء الملف التنفيذي على Windows دون الحاجة إلى تثبيت Python على جهازك.

طريقة الحصول على EXE:
1) أنشئ مستودعاً جديداً على GitHub.
2) ارفع محتويات هذا المجلد إلى المستودع، بما فيها .github/workflows.
3) افتح Actions ثم اختر "Build ACS150 Simulator for Windows 10 x64".
4) اضغط Run workflow (أو ادفع الملفات إلى فرع main).
5) بعد نجاح البناء، نزّل Artifact باسم ACS150_Simulator_Windows10_x64.
6) فك الضغط وشغّل acs150-simulator.exe على Windows 10 64-bit.

المشروع مكتوب بلغة Rust ويستخدم مكتبة egui/eframe للواجهة.
Rust وCargo موجودان في بيئة البناء السحابية فقط. لا يحتاج جهاز التشغيل
إلى Python أو Rust أو تثبيت runtime خاص بالمشروع.

الوظائف الحالية:
- لوحة LCP افتراضية مبسطة.
- START / STOP / RESET.
- مرجع تردد 0–50 Hz مع محاكاة ramp.
- اختيار الاتجاه FWD/REV.
- قائمة Parameters أولية.
- أعطال تجريبية F0001 وF0002 وF0004.

مهم:
لم يتم بناء EXE أو اختباره فعلياً في هذه الجلسة. القيم وسلوك المعلمات
أولية تعليمية ويجب مطابقتها مع دليل ABB للطراز والبرنامج الثابت المحددين.
هذا البرنامج لا يتصل بإنفرتر حقيقي ولا يتحكم به.
